Approximate a multivariate integral by using the randomized Crude Quasi-Monte Carlo integration by sampling from the Weyl sequence.

The total number of points N is distributed over M random shifts, and the variance of the estimates is used to compute the final error.

Parameters
fThe function to integrate
extremesA vector of the extremes of integration
alphaAn irrational number
NThe number of points to generate (expected to be a multiple of M)
MThe number of random shifts to use
