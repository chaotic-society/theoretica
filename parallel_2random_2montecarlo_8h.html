Approximate an integral by using the randomized Crude Quasi-Monte Carlo integration by sampling from the Weyl sequence.

The total number of points N is distributed over N_shift random shifts, and the variance of the estimates is used to compute the final error.

Parameters
fThe function to integrate
aThe lower extreme of integration
bThe upper extreme of integration
NThe total number of points to generate (assumed to be divisible by N_shift)
N_shiftThe number of random shifts to use
